# Venture English — приложение для iPhone

Тренажёр слов по учебнику «English for Entrepreneurs (B1–B2)», юниты 1–8.
После установки на экран «Домой» открывается как обычное приложение и работает без интернета.

## Как установить (один раз, бесплатно, через GitHub Pages)

1. Зарегистрируйтесь на github.com.
2. Создайте новый репозиторий: «+» → «New repository», имя `venture-english`, тип **Public**, «Create repository».
3. В репозитории выберите «Add file» → «Upload files» и загрузите **все файлы из этой папки**: `index.html`, `sw.js`, `manifest.webmanifest`, четыре файла `icon-…png` и `README.md`. Нажмите «Commit changes».
   На iPhone: откройте zip-архив в приложении «Файлы» (он распакуется в папку), затем на сайте GitHub выберите файлы из этой папки.
4. Откройте «Settings» → «Pages». В «Source» выберите «Deploy from a branch», ветку `main`, папку `/ (root)` и нажмите «Save».
5. Через 1–2 минуты приложение будет доступно по адресу `https://ВАШ-ЛОГИН.github.io/venture-english/`.
6. Откройте этот адрес в **Safari** на iPhone → кнопка «Поделиться» → «На экран „Домой“» → «Добавить».
7. Первый раз запустите приложение с иконки при включённом интернете. После этого оно работает и без сети.

Сайт публичный: открыть его сможет любой, у кого есть ссылка.

## Прогресс

Прогресс хранится на телефоне. Чтобы перенести его из версии в Claude или на другое устройство:
«Профиль» → «Скопировать код прогресса» в одной версии и «Вставить код» в другой. Прогресс объединяется, ничего не теряется.

## Обновление

Загрузите новые файлы в тот же репозиторий поверх старых. Приложение подхватит обновление при следующих запусках с интернетом.
